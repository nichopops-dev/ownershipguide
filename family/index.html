Plan the household across both ends of the family timeline.

A baby, formal childcare, school, a second child or an aging parent's care needs can change the same limited pool of time, cash, housing capacity and transport. Start with the life stage creating pressure now, then test how the decision affects the rest of the household.

FAQ

What should families plan for beyond childcare costs?

Plan for education, housing and transport choices, changes to work, insurance and cash reserves, and the possibility of supporting aging parents at the same time.

Where should I start if an aging parent needs more help?

Start with the supporting aging parents guide to map the care load, compare home and centre services, check grants and assign clear family roles before changing housing or employment.

How should I use the Family hub?

Choose the lane that matches the current life stage, read the anchor guide first, and then use the linked comparison or calculator for the specific decision.
